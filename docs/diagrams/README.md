# README diagrams

The diagrams in the top-level README, each in a light and a dark version. They follow [the brand style](../brand/style.md): cards extruded at the mark's 30° and VMs drawn as the mark's cube.

| Diagram | Generated by | What it shows |
| --- | --- | --- |
| `hero-*.svg` | `hero.py` | Coding agents using boxery to spin up, fork, snapshot and throw away VMs, locally, on a remote box or in the cloud |
| `host-*.svg` | `host.py` | The trusted boxery host between your agents and the untrusted VMs, and the token swap |
| `layers-*.svg` | `layers.py` | Which program fills each virtualization layer, per backend |
| `works-with-*.svg` | hand-made | The backend logo row. [`social-card.py`](../brand/social-card.py) reuses its logos |

`parts.py` holds what the generated diagrams share: both themes' colors, the slab, the cube and its states, arrows, and the agent logos.

Edit a script, then regenerate every diagram (Python 3, no dependencies):

```sh
python3 docs/diagrams
```
